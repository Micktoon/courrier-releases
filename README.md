# OutCraft

Versions publiées d'OutCraft, client mail de bureau pour Windows et macOS (IMAP/SMTP multi-comptes, calendrier, contacts, tâches).

Ce dépôt ne contient que les installateurs et les fichiers `latest.yml` / `latest-mac.yml` lus par les applications installées pour se mettre à jour automatiquement. Le code source est dans le dépôt privé `logiciel-mail`.

Les versions 0.3.x correspondent à l'ancien projet « Courrier » et ne sont plus maintenues.
